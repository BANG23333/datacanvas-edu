# Contributing

DataCanvas EDU is a public prototype. Feedback from the researcher and other users will guide subsequent revisions.

Useful contributions include clearer instructor questions, reproducible failures, tested installation instructions, better reference visualizations, and cases from additional business domains. Keep domain rules and grading scales in case configurations rather than hard-coding them into the shared Skill.

Describe the actual teaching need, expected behavior, observed behavior, environment, and version. Use the smallest example that demonstrates an issue. Mark suggested defaults and unresolved instructor decisions explicitly. Preserve unsuccessful results instead of selecting only successful seeds or easy examples.

Write documentation, code, comments, and generated project materials in English. Run the existing behavioral checks when changing the helper, and verify affected example behavior. A new business case should include a teaching brief, generation specification, executable generator, and checks for the intended discoveries.

License and formal contribution arrangements remain to be finalized.
