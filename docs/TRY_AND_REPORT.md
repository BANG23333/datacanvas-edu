# Researcher Trial and Feedback

The first researcher trial exposed premature generation and expansion into two assignments; v0.1.2 addressed those issues. Version 0.1.3 responds to follow-up feedback by adding explicit output-format choices and a visible instructor review-and-revision loop. See the [first trial record](TRIAL_FEEDBACK_V0.1.2.md) and [changelog](../CHANGELOG.md). Core numerical behavior is unchanged, and prior artifacts remain available for comparison.

Start with a fresh conversation and a real teaching brief. Any business domain is welcome. Let the Agent conduct the interview and prepare the technical specification; manually running a supplied example tests the helper, not the conversational Skill.

Check whether the Agent asks what hidden patterns you want, gives useful proposals, and waits for your response. It should next show one assignment, a concrete rubric, and what output files you will receive, recommend formats, and wait for approval before generation. It must distinguish the instructor's document formats from student submission formats. A choice such as "both" for analytical methods must not become two assignments or blanket approval.

At first delivery, check that the Agent explains you can return to planning and invites concrete feedback. Inspect the pattern-by-pattern solution, charts, explanations, discovery credit, and deductions. Request one change in plain language, such as making a pattern subtler or simplifying the rubric. Check that the Agent keeps settled decisions, asks only about unresolved choices, preserves earlier versions, and revises the right artifacts. A rubric-only revision should not change the dataset. You can accept a version when it fits; repeated revision is available, not compulsory.

Feedback can be informal. Useful details include:

- Tool/surface, model if known, Skill version, and installation route.
- Your initial teaching brief and the materials returned.
- Steps that were confusing, repetitive, failed, or required manual repair.
- Whether the scenario, patterns, difficulty, reference analyses, and rubric matched your intent.
- Requested changes and the Agent's response.
- Any conversation record, error message, or small reproducible example you are willing to share.

The first trial and subsequent feedback are formative, not a controlled usability or student learning study. A complete instructor trial of v0.1.3 through actual exports and a revision cycle remains necessary. Record actual observations, keep unsuccessful attempts, and distinguish improvements in conversational control from numerical checks or learning outcomes.
